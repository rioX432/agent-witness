# Security Policy

**agent-witness is an observation and audit tool. It is NOT a security boundary.**
It records what AI agent sessions report via hooks; it does not prevent, sandbox, or guarantee detection of malicious activity. Known observation gaps are documented in NON-GOALS.md and the README.

## Reporting a vulnerability

Please email rio@anotherball.com with details. You should receive a response within 72 hours. Please do not open public issues for security reports.
